# Original six storefront templates

The existing renderers, CSS and 12 WebP assets are reused from [Coco9 Storefront UI](https://github.com/lincwang123-bot/coco9-storefront-ui), revision `b677171585ce2dc2bdd978f8e560b0f4d528eeb1`. The 25 original files were byte-for-byte identical when this integration began. Their original MIT license is retained in `LICENSE`; image provenance is in `ASSETS.md`.

The original templates predate this competition work. TapeCommerce adds order/payment integration; it does not claim to have created the six themes during the event. New `commerce.js` is an integration module and follows its own SPDX GPL-3.0-only declaration.

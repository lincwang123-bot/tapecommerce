# Protocol and data boundaries

- Network: X Layer, chain ID 196. The read-only adapter pins a safe block, reads the supported factory/identity state, and rechecks the block hash. It does not create a wallet or send transactions.
- Factory: `0x1f09daefa827f02cbb40967cc91b259763760761`; Opener: `0x536add8f30f03b69f6fbf29d425a816a0dc50106`; SiteRegistry: `0xd6efb7adcc9c83dc4924ad56f6a8e4e969b9adb6`; binding: `0x68809fd2fb343aa57d0aeb7f33defe477c9666f9`. Addresses/expected implementations are pinned in `scripts/tapecommerce/readonly-adapter.mjs` and must fail closed on unexpected upgrades.
- The default public sample is processor 2 / token 1, commonly named `1.2.2.tape`. It is not owned or operated by TapeCommerce. Real holder/container/live values come from the query, not hardcoded ownership claims.
- OKX endpoint: `https://openapi.okx.com/api/v5/market/ticker?instId=OKB-USDT`. Require successful JSON, one `SPOT` / `OKB-USDT` row, canonical positive decimal `last` and millisecond `ts`, size/time limits and business freshness checks. `last` is a last-trade price; `ts` is the ticker snapshot time, not the time of the last trade. Source availability is checked at runtime; no stale-price fallback or arbitrary host input.
- Quotes keep immutable source/price/time/rounding metadata. The 30-second freshness, future-clock tolerance and roughly 60-second lock are application policies, not an OKX service guarantee. USDT is not a guaranteed fixed USD amount.
- The showcase uses an isolated Anvil chain with random disposable wallets. It executes the real compiled checkout and original Go order/stock flow, but its balance and transaction receipts have no mainnet value. Two local RPC transport paths share one chain and are not an independent-node quorum.
- The production Go commerce router is not activated by the demonstration. DeWEB write/publish execution, an owned TapeOut store, real-wallet checkout and an independent security audit remain separate work.

Official references: [TapeKit pinned configuration](https://github.com/TapeOutProtocol/TapeKit/blob/40994bd65baedbda4df72cb0985031a5f082f606/kernel/src/config.js), [OKX ticker API](https://www.okx.com/docs-v5/en/#order-book-trading-market-data-get-ticker), [X Layer documentation](https://web3.okx.com/xlayer/docs). The pinned commit records what was verified; recheck upgrades before enabling production payments.

# 原模板与真实钱包接线验收 · 2026-10-17

本轮开发复用原六套 Coco9 模板、12 张原图和原订单确认/详情结构，保留旧 USDT、余额与充值模块。它修正了上一版公开 showcase 单独设计前台的偏差。原模板先于活动存在，不算本次从零开发。

已验收范围：

- 六模板在 1440×1100、390×844 共12个布局均无缺图、无横向溢出。
- 桌面和手机均完成选商品→确认订单→真实 OKX 报价→隔离 Anvil 合约付款→原 Go 库存交付→下载 HTML→刷新恢复；应用 console/pageerror 为0。TapeOut 只读查询和中英文切换通过。
- 原商城前端会员桌面、游客手机，使用隔离 EIP-1193 钱包/API fixture 完成精确报价、主动发起交易、提交hash、以服务端 delivered 为准显示交付。访客请求支付配置不带查单凭据；实际会员和游客订单接口沿用各自鉴权。
- 原 web 测试179项通过，其中16项为钱包专项。覆盖ABI与ethers独立golden一致、金额/domain/链/付款账户篡改拒绝、账户变化丢弃晚报价、发送超时保留不确定标记、4001取消、导航后的晚交易hash持久化与提交。
- Node signer/FX/只读协议测试79项通过。真实safe区块、代码hash、domain、链上quoteSigner、当前TapeOut持有人与原Studio nonce绑定为报价前置；并发与超时取消均验证。
- Showcase服务测试7项通过；静态文件采用逐项白名单，原API客户端/管理页/配置不可从演示服务访问。新增公开源码扫描覆盖最新双语表单字段与私有收款地址，扫描规则测试2项通过。

第一次本机浏览器运行遇到真实 `fx_source_timeout`，系统按设计拒绝报价；使用本机已有网络代理后完成全流程。没有改价格或用旧报价兜底；VPS网络设置没有因此改变。

上述钱包浏览器测试使用mock，付款端到端使用隔离链，两者均**不构成主网真钱付款验收**。自有TapeOut身份/nonce控制权绑定、主网合约、独立报价签名账户与两家独立RPC仍待启用前准备。原商店生产没有在此轮接入测试中变更；报名保持暂停，未填写或提交表单。

浏览器结果见 [JSON](template-payment-integration.json)。本地 Node/Anvil/Go 临时服务已正常停止并按记录PID核对退出；Playwright浏览器已关闭。授权常驻VPS演示服务按部署生命周期管理。
